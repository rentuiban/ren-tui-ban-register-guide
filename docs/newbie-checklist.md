# 任推邦注册核对清单

> 注册任推邦之前，逐项过一遍，避免注册后才发现不符合预期。

## 注册前

- [ ] 认准官方入口：[rentuibang.app](https://rentuibang.app/)，不要使用第三方转述页面
- [ ] 准备好本人实名手机号（用于验证码与实名认证）
- [ ] 了解结算模式：T+1 结算、满 10 元提现、1-3 个工作日到账
- [ ] 想好自己的流量类型（自媒体 / 社群 / 线下），影响首个项目选择

## 注册时

- [ ] 邀请码与手机号填写无误（提交后通常不可更改）
- [ ] 实名信息与身份证一致（影响佣金结算）
- [ ] 记录注册时间，保存客服入口

## 注册后第一周

- [ ] 跟官方教程跑通一个项目（推荐网盘拉新：[夸克教程](https://rentuibang.app/articles/tutorials/how-to-register)）
- [ ] 生成专属推广链接，自己先完整走一遍流程
- [ ] 发布到自己的渠道，观察数据
- [ ] 首笔佣金到账后，设置提现方式（支付宝 / 微信 / 银行卡），验证闭环
- [ ] 遇到问题先联系平台客服（官网有入口）

## 判断渠道是否靠谱

- 佣金规则后台明示、提现记录可查
- 客服不回避结算周期、完税等细节问题
- 平台主体信息透明（任推邦隶属聚名科技集团，企查查可查）
